- 키워드 검색, 과목·단원 목차, 관련 기출, 기기 내 글 저장, 인쇄

## 수정과 배포

`content/`의 과목별 JSON을 수정합니다. 글은 `id`, `subject`, `category`, `title`, `summary`, `tags`, `body`(Markdown), `refs`를 가집니다. `refs`는 원문 표기이며 실제 문항을 검증한 경우에만 별도 `*-reference-checks.json`에 번호와 근거를 넣습니다.

Node.js와 Python이 필요합니다. 패키지 설치 후:

```sh
pnpm install --frozen-lockfile
python tools/check.py
python tools/build.py
python -m http.server 4173 --directory docs --bind 127.0.0.1
```

`web/`은 화면 코드, `docs/`는 생성된 GitHub Pages 배포본입니다. 수정 후 빌드한 `docs/`까지 함께 커밋합니다. Pages는 `main` 브랜치의 `/docs`를 사용합니다. 외부 CDN에 의존하지 않도록 Markdown·수식 라이브러리를 배포본에 포함합니다.

`tools/fetch_exams.py`는 requests와 beautifulsoup4를 사용해 공식 목록의 메타데이터를 수집합니다. 문제지 원본을 재배포하지 않습니다. 갱신 시 확인일과 새 자료의 대상 체계를 확인합니다.

## 편집과 출처

원문에 있는 판단 순서·계산 요령·조건을 보존하고 중복을 통합했습니다. 개인 점수·날짜·신상과 입시 기록은 제외했습니다. 의미가 달라질 수 있는 정정과 원본 수록표는 작성자의 로컬 편집 기록에서 관리합니다. 이 저장소에는 개인 원문과 로컬 조사 파일을 포함하지 않습니다.

기출의 학년도와 실제 시행 연도는 구별합니다. `2406`은 2024학년도 6월 모의평가입니다. 원문에 문항번호가 없거나 출처가 불명확하면 특정 문항으로 단정하지 않습니다.

문제지·정답의 권리는 한국교육과정평가원 및 해당 권리자에게 있습니다. 본 사이트의 기출 자료실은 공식 게시물과 첨부파일을 연결합니다. 학습 노트와 공식 문제지의 제공 범위는 서로 다릅니다.

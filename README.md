# 수능 판단 노트

실제 공부 기록에서 정리한 과목별 강령, 풀이 분석, 실수 방지와 학습 팁을 찾아 읽는 위키입니다.

- [사이트](https://devkyber.github.io/csat-study/)
- 국어·수학·영어·물리학Ⅰ·지구과학Ⅰ·공통 공부법
- 2027학년도까지의 수능 체계, 언어와 매체 학습 노트 제외
- 설명 바로 아래 실제 기출 이미지, 펼쳐 보는 판단 과정과 정답
- 별도 5개년 분석: 2022–2026학년도 6월·9월·수능 75회, 2,400문항의 문제와 단계별 풀이
- 잠깐 공부: 선택한 한 과목의 짧은 퀴즈·회상·팁, 기출 영단어를 3·5·10장씩 반복
- 평가원·EBSi 문제지·정답·듣기 자료를 PDF/음원으로 직접 연결
- 개별 PDF가 없는 옛 시험은 표지를 대조한 공개 보관본과 보관소 출처 표시
- 노트·카드·영단어 검색, 과목·단원 목차, 기기 내 글 저장, 명암 테마, 인쇄

## 노트와 문제의 관계

2017–2026학년도 6월·9월·수능을 과목별로 검토했습니다. 국어는 공통 독서·문학의 제재와 문항 범위, 수학·영어·과탐은 문항 유형을 분류하고, 노트의 판단을 적용할 문제를 골라 그림·조건·정답을 추가 대조했습니다. 이 10개년 분류는 노트에 붙일 예시를 찾기 위한 것이며, 문항별 전체 풀이는 아래 5개년 분석에서 제공합니다. 원문에 있던 더 오래된 작품·문항과 예시문항은 최근 10개년과 구분해 유지합니다.

원문의 강령·조건·계산 요령은 짧은 소제목과 bullet로 정리했습니다. 일반적인 공부 습관은 실행할 행동과 예시로 설명하고, 과목별 판단에는 실제 기출을 붙입니다. 문제 전체가 그 소제목의 모든 사실을 묻는다고 단정하지 않으며, 대응하는 조건과 연습할 판단을 문제 위에 적습니다.

화면은 사용자가 지정한 [PSI 홈페이지](https://github.com/postech-psi/postech-psi.github.io)와 [시험 기록](https://github.com/postech-psi/test-results)의 Pretendard·흑백 바탕·구분선·제한된 강조색을 학습용 목차와 읽기 화면에 적용했습니다. 로고와 팀 사진은 사용하지 않습니다.

## 5개년 기출 분석

[5개년 분석](https://devkyber.github.io/csat-study/#/practice)은 노트와 별도로 읽는 문항별 풀이입니다. 2022–2026학년도에 시행된 6월·9월 모의평가와 수능을 포함합니다.

| 과목 | 범위 | 문항 수 |
| --- | --- | ---: |
| 국어 | 공통·화법과 작문 | 675 |
| 수학 | 공통·미적분 | 450 |
| 영어 | 듣기·독해 | 675 |
| 물리학Ⅰ | 전 문항 | 300 |
| 지구과학Ⅰ | 전 문항 | 300 |

각 문항은 실제 문제, 번호를 붙인 판단·계산 단계, 정답, 다시 풀 때 확인할 점, 관련 노트로 구성합니다. 풀이를 열면 첫 단계부터 보이고, 다음 단계를 하나씩 열거나 전체 풀이를 볼 수 있습니다. 마지막 단계까지 열면 별도의 정답과 복습 요령도 표시합니다. 기존 풀이 문장 자체에 답이 포함된 경우가 있어 ‘정답 없는 힌트’로 표시하지 않습니다. 원문 노트에서 확장한 새 풀이이며, 모든 풀이가 작성자의 원래 메모에 있었다고 표시하지 않습니다. EBS 해설을 대조 자료로 사용하고 풀이 문장은 직접 작성했습니다. 영어 듣기는 공식 전체 음원과 대본을 함께 제공합니다.

문제 화면은 PDF.js로 EBSi의 평가원 문제지 원본을 읽습니다. 개별 문항은 그림과 선지가 남도록 확대합니다. 국어는 왼쪽 열 다음 오른쪽 열을 크게 보여 주고, 공통 지문이 이어지면 필요한 원본 쪽을 이동하며 읽습니다. 언제든 전체 쪽과 원본 PDF를 열 수 있습니다. ‘다시 풀어 볼래요’와 ‘다시 풀 수 있어요’ 기록은 현재 브라우저에만 저장됩니다.

PC·태블릿에서는 왼쪽 문항 목록을 스크롤 중에도 유지합니다. 현재 문항과 복습·완료 상태를 표시하며, 목록 안에서 방향키와 Home·End로 이동할 수 있습니다. 좁은 휴대폰에서는 하단의 ‘문항 선택’ 버튼으로 전체 번호를 열고 고릅니다.

풀이에서 관련 노트를 읽고 뒤로 돌아오면, 같은 탭에서 열어 둔 풀이와 PDF 보기 상태를 복원합니다. 여러 탭에서 문항 복습을 표시해도 다른 문항의 기록을 덮어쓰지 않습니다.

## 변곡점 풀이법을 처음 배울 때

[삼차함수 노트](https://devkyber.github.io/csat-study/#/read/math-cubic)는 함수의 높이·기울기·기울기의 변화를 구별한 뒤 점대칭, 평행 접점의 중점, 접선 차이함수와 1:2를 유도합니다. [사차함수 노트](https://devkyber.github.io/csat-study/#/read/math-quartic)는 3:1·2:1:1·1:√2와 공통접선을 적용 조건부터 설명합니다. 접점과 변곡점이 겹치는 경우, 가로거리와 높이 차, 원함수와 도함수의 극점을 구별합니다.

그래프 3개에서 도함수와 원함수를 비교하고 접점을 옮겨 볼 수 있습니다. 그림은 이해를 위한 새 예시이며 실제 평가원 문항은 바로 아래에 별도로 제시합니다. 원노트의 압축된 판단을 풀이 단계로 확장하고, 공개 교재와 공식 기출을 대조했습니다. `mathLabs`의 `type`과 `afterHeading`으로 본문의 소제목에 그림을 연결하고, `afterText`로 짧은 예제 바로 뒤에 배치합니다. `tools/check_math_geometry.mjs`는 접점·교점·대칭과 비율을, `tools/check_math_lessons.cjs`는 수식과 삽입 위치를 검사합니다.

## 잠깐 공부

[잠깐 공부](https://devkyber.github.io/csat-study/#/bites)는 기존 노트와 기출 분석을 바탕으로 새로 만든 짧은 연습입니다. 전체 기출을 끝까지 풀지 않고 조건·비교 기준·발상 하나를 연습합니다. 830개 카드가 기존 122개 노트에 연결됩니다.

| 과목 | 카드 수 | 주로 연습하는 판단 |
| --- | ---: | --- |
| 국어 | 140 | 지문 근거, 주체·범위, 보기 적용, 문학의 표현과 효과 |
| 수학 | 150 | 경계·부호·대응점, 계산을 줄이는 발상, 공식의 적용 조건 |
| 영어 | 230 | 기출 영단어 160개, 문장의 논리·범위·연결과 듣기 정보 |
| 물리학Ⅰ | 120 | 기준계·방향·비교 조건, 그래프와 물리량 |
| 지구과학Ⅰ | 140 | 자료의 축·시점·단위, 원인과 결과, 같은 조건에서의 비교 |
| 공부법 | 50 | 오답 원인에 따른 다음 행동, 복습과 실전 판단 |

숫자만 바꾼 반복 문항을 늘리지 않고, 기존 카드에서 다루지 않은 조건·오개념·적용 상황을 추가합니다. 각 카드는 주어진 내용만으로 답할 수 있어야 하며, 정답 근거와 다음에 쓸 요령을 짧게 남깁니다. 새 카드의 정답·조건·노트 근거를 다른 검수자가 다시 확인하고, 문장이 비슷한 카드는 학습 목표까지 비교합니다. 기존 카드 ID와 내용을 유지해 복습 기록을 이어 갑니다.

원래 기출의 문장이나 수치 그대로라는 뜻은 아닙니다. 단어는 실제 기출 문맥의 뜻을 확인하고 새 예문과 전체 문장 해석을 작성했습니다. 특정 문항과 판단이 직접 대응하는 경우에만 기출 번호를 붙이며, 그 외에는 근거가 된 노트를 연결합니다.

노트의 ‘이 노트 연습’에서는 해당 노트에 연결된 카드만 고릅니다. 영어 노트는 단어 카드에 치우치지 않도록 판단 퀴즈부터 엽니다. 기출 풀이에서는 정확히 그 문항에 연결된 짧은 연습을 먼저 제공하고, 없으면 관련 노트의 연습으로 안내합니다. 카드가 적으면 그 수만큼 끝내며 다른 주제의 카드로 채우지 않습니다.

검색은 카드 제목·주제·태그·단어·질문·예문을 찾되, 정답과 해설은 펼치기 전까지 숨깁니다. 카드에서 노트나 기출로 이동해도 ‘보던 카드로 돌아가기’로 이어 볼 수 있습니다. 개별 카드의 선택과 답 공개 상태도 같은 탭에서 오가는 동안 유지됩니다.

기본은 선택한 한 과목의 5장입니다. 마지막 과목과 진행 중인 묶음, 답 공개 상태를 기억합니다. 맞혔어도 헷갈린 카드는 다시 볼 수 있고, 건너뛴 카드는 학습 완료로 세지 않습니다. 틀리거나 모르는 카드는 다시 볼 목록에 남습니다. 기본 섞기에서 10분 뒤부터 복습 대상이 되고, 기억한 카드는 1·3·7·14·30일 간격을 사용합니다. 이는 간단한 복습 순서이며 실력·숙달도 예측 모델은 아닙니다. ‘다시 볼 것’에서는 예정 시각 전에도 헷갈린 카드를 골라 볼 수 있습니다.

`content/bites/<subject>.json`이 원본입니다. 각 카드의 `kind`는 `choice`, `recall`, `tip`, `vocab`이며 `prompt`, `explanation`, `takeaway`, `noteIds`, `refs`로 판단과 출처를 연결합니다. 선택형의 `answer`는 0부터 시작하는 선택지 인덱스입니다. 단어의 `term`과 `example`은 반드시 함께 표시합니다. 정답·자기완결성·조건 보존·기출 연결을 검수하고 `tools/check_bites.py`, `tools/check_bite_render.cjs`로 누락·수식·노트 전체 범위를 확인합니다.

복습 기록은 브라우저에 저장합니다. 같은 브라우저의 여러 탭은 최신 기록을 합칩니다. 기기 간 자동 동기화는 없으며, 화면의 기록 파일 저장/가져오기로 다른 폰·태블릿에 옮길 수 있습니다. 가져오기는 더 최근 기록과 모아둔 카드를 보존하고 진행 중인 묶음을 바꾸지 않습니다.

서비스워커는 앱 코드·폰트·텍스트 노트·짧은 카드만 미리 저장합니다. 준비가 끝난 기기에서는 짧은 공부를 오프라인으로 다시 열 수 있습니다. 기출 PDF·음원·문제 이미지는 미리 받지 않습니다. 브라우저 데이터가 삭제되면 오프라인 자료와 기록도 사라질 수 있습니다. 홈 화면 추가는 브라우저가 지원하는 방식으로 제공합니다. 새 버전은 별도 캐시에 준비한 뒤 ‘새로고침해 받기’를 누를 때 적용합니다. `tools/build.py`가 내용 해시를 사용해 `docs/sw.js`를 생성하므로 `web/sw.template.js`를 편집합니다.

## 수정과 배포

### 빌드

`content/`의 과목별 JSON이 글의 원본입니다. 글은 `id`, `subject`, `category`, `title`, `summary`, `tags`, `body`(Markdown), `refs`를 가집니다. `refs`는 원문 표기이며 실제 문항을 검증한 경우에만 별도 `*-reference-checks.json`에 번호와 근거를 넣습니다.

`*-examples.json`의 `examples`에는 `articleId`, `afterHeading`(본문 소제목과 정확히 일치), 학년도·회차·문항, `sourceUrl`, `image` 또는 `images`, `prompt`, `explanation`(Markdown 문자열), `answer`를 넣습니다. 이미지는 `web/examples/`에 둡니다. `variant`에는 가형·나형·A형·짝수형 등의 판본을 표시합니다. 소제목을 바꿀 때 예시의 `afterHeading`도 함께 수정합니다. 빌드는 이미지 크기를 읽어 화면이 뒤늦게 밀리지 않도록 배포 데이터에 포함합니다.

`content/practice/<subject>/<subject>-YYYY-MM.json`은 한 회차의 풀이입니다. `questions`의 `number`, `page`(PDF 물리 페이지, 1부터), `pages`(함께 읽을 지문 쪽), `answer`, `topic`, `steps`, `check`, `noteIds`를 편집합니다. `sourceUrl`은 문제 PDF, `answerSourceUrl`은 대조한 해설 PDF입니다. `content/practice-regions.json`은 원본 PDF의 정규화된 보기 영역으로, 빌드 때만 배포 데이터에 합칩니다. 원문 그림·선지·공통 지문이 잘리지 않는지 반드시 확인합니다.

Node.js와 Python이 필요합니다. 패키지 설치 후:

```sh
pnpm install --frozen-lockfile
python -m pip install -r requirements.txt
pnpm check
python tools/build.py
python -m http.server 4173 --directory docs --bind 127.0.0.1
```

`web/`은 화면 코드, `docs/`는 생성된 GitHub Pages 배포본입니다. 수정 후 빌드한 `docs/`까지 함께 커밋합니다. Pages는 `main` 브랜치의 `/docs`를 사용합니다. Pretendard와 Markdown·수식·PDF 표시 라이브러리는 배포본에 포함합니다. 로그인 없이 공개 열람하며 글 저장과 문항 복습 기록은 현재 브라우저에만 남습니다.

`tools/fetch_exams.py`는 평가원 게시물 메타데이터, `tools/pdf_sources.py`는 EBSi 개별 파일 링크를 수집합니다. `content/legacy-pdfs.json`은 공식 개별 PDF가 없는 회차의 공개 보관본 링크와 검토 기록입니다. 갱신할 때 파일의 PDF 응답뿐 아니라 표지의 학년도·회차·과목·유형도 확인해야 합니다. 전체 문제지를 이 저장소에 복제하지 않습니다.

`tools/check.py`는 글 ID, 모든 과목별 소제목의 예시 연결, 이미지 경로, 출처, 판본 자료와 보관본 검토 기록을 검사합니다. 배포 전에는 실제 브라우저에서 수식, 문제 이미지, 피드백, 확대, 목차 링크, 검색·저장과 모바일 화면도 확인합니다.

`web/markdown.mjs`는 노트·카드·기출 풀이가 함께 사용하는 Markdown 표시 규칙입니다. `수십~수천` 같은 범위 표기를 보존하고 `~~취소선~~`처럼 명시한 경우만 취소선을 만듭니다. `tools/check_markdown.mjs`가 범위·수식·표·코드의 표시를 검사합니다.

## 편집과 출처

원문에 있는 판단 순서·계산 요령·조건을 보존하고 중복을 통합했습니다. 개인 점수·날짜·신상과 입시 기록은 제외했습니다. 의미가 달라질 수 있는 정정과 원본 수록표는 작성자의 로컬 편집 기록에서 관리합니다. 이 저장소에는 개인 원문과 로컬 조사 파일을 포함하지 않습니다.

기출의 학년도와 실제 시행 연도는 구별합니다. `2406`은 2024학년도 6월 모의평가입니다. 원문에 문항번호가 없거나 출처가 불명확하면 특정 문항으로 단정하지 않습니다.

문제지·정답의 권리는 한국교육과정평가원 및 해당 권리자에게 있습니다. 학습 예시에는 분석에 필요한 문항·지문 대목만 발췌하고 출처를 연결합니다. 전체 시험지는 공식 파일 또는 출처를 표시한 보관본 링크로 제공합니다. 학습 노트와 전체 시험지의 제공 범위는 서로 다릅니다.
